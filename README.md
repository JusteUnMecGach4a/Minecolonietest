# 🌍 MineColonies & Create Server - Guide de Connexion

Ce guide explique comment rejoindre facilement le serveur moddé MineColonies & Create.

---

## 🌐 Informations du Serveur
* **Version de Minecraft** : `1.21.1`
* **Modloader** : `NeoForge 21.1.248`
* **Adresse IP** : `minecolonietest.falixsrv.me:26137`
* **Dashboard Web (Colonie)** : [ColonyWeb Dashboard](http://eu21-free.falixserver.net:20017)

---

## 📥 Comment rejoindre le serveur

### Étape 1 : Installer le Modloader
1. Téléchargez et installez **NeoForge version 21.1.248** pour Minecraft 1.21.1.
2. Lancez le jeu une première fois avec ce profil NeoForge pour générer les dossiers, puis fermez le jeu.

### Étape 2 : Télécharger et installer les Mods
Pour pouvoir vous connecter, vous devez copier tous les mods listés ci-dessous dans le dossier `mods` de votre jeu Minecraft (accessible via `%appdata%\.minecraft\mods` par défaut, ou via votre dossier d'instance personnalisé CurseForge/Prism).

---

## 📦 Liste des Mods Requis (Côté Client)

Tous ces mods doivent être installés dans votre dossier `mods` local :

### 🤝 Mods requis pour la connexion au serveur
* **MineColonies** (`minecolonies-1.1.1374-1.21.1-snapshot.jar`)
* **Create** (`create-1.21.1-6.0.10.jar`)
* **CreateColonies** (`createcolonies-2.0.6.jar`)
* **Create: Colony Logistics** (`create_colony_logistics-1.3.1.jar`)
* **Structurize** (`structurize-1.0.832-1.21.1.jar`)
* **BlockUI** (`blockui-1.0.211-1.21.1-snapshot.jar`)
* **Domum Ornamentum** (`domum-ornamentum-1.0.234-snapshot-main.jar`)
* **Multi-Piston** (`multipiston-1.2.58-1.21.1.jar`)
* **Vanilla Food Compatibility** (`minecoloniesvanillafoodcompat-1.0.0.jar`)
* **ColonyWeb** (`colonyweb-1.21.1-neoforge-1.0.1.jar`)
* **Craftable Crops** (`craftable_crops-1.0.0-neoforge-1.21.1.jar`)
* **MineColonies QoL** (`minecolonies_qol-1.0.0___1.1.921-1.21.1.jar`)
* **JourneyMap** (`journeymap-neoforge-1.21.1-6.0.5.jar`)
* **Kotlin for Forge** (`kotlinforforge-5.12.0-all.jar`)
* **MCTier Library** (`mctier_engine-1.0.0.jar`)
* **Just Enough Items (JEI)** (`jei-1.21.1-neoforge-19.27.0.340.jar`) *(Note : utilisez cette version spécifique pour éviter les crashs avec la manette)*

### 🎮 Mods Client recommandés (Optionnel)
Ces mods améliorent votre confort de jeu local sans être requis par le serveur :
* **Controllable** (`controllable-neoforge-1.21.1-0.25.4.jar`) - Pour jouer avec une manette de console.
* **Framework** (`framework-neoforge-1.21.1-0.13.11.jar`) - Requis si vous utilisez *Controllable*.
* **Embeddium** (`embeddium-1.0.15+mc1.21.1.jar`) - Améliore grandement les FPS.
* **Mouse Tweaks** (`MouseTweaks-neoforge-mc1.21-2.26.1.jar`) - Raccourcis pour trier les coffres et inventaires.
* **Configured** (`configured-neoforge-1.21.1-2.6.3.jar`) - Interface en jeu pour modifier la configuration des mods.

---

## ⚙️ Notes de compatibilité importantes
* **Compatibilité Manette (JEI + Controllable)** : Si vous jouez à la manette via *Controllable*, veillez à bien utiliser la version **JEI 19.27.0.340** ou inférieure pour éviter un plantage lors du chargement des recettes.
